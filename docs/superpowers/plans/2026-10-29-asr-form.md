# ASR Form Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Fill a selected contact field using Gipformer and Silero without LLM.
**Architecture:** Reuse the controller, audio transport and runner. Add a form
session/client and UI through small controller extension points.
**Tech Stack:** Existing Python, Gradio, numpy, Silero and Gipformer.
**Spec:** ../specs/2026-10-29-asr-form-design.md

## Global Constraints
- No new runtime dependencies. No LLM or TTS in form mode.
- Preserve the conversation entry point and its tests.
- No automatic submission or server persistence of form data.

## Review Focus
- Switching fields during recognition keeps the original audio target.
- Manual edit/clear wins over pending recognition.
- Invalid or empty phone transcription preserves existing form data.
- Multiple browser sessions retain independent forms.
- Colab runs changed local source rather than silently cloning old remote code.
